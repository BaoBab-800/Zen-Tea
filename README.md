# Zen tea

A Flutter app that recommends tea based on weather, time of day and user mood.
- weather conditions
- time of day
- personal preferences
- offers mini-stories for each tea
- tea card collection

## Getting Started

### 1. Clone repository
git clone https://github.com/BaoBab-800/Zen-Tea.git

### 2. Install dependencies
flutter pub get

### 3. Run app
flutter run
